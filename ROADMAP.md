# 🔖 Mona's Bookmark Manager — Roadmap

Save links, get short slugs, keep them forever—right in your browser.

## Overview

| Area | Item | Type | Priority |
|------|------|------|----------|
| Core Feature | Search & filter bookmarks | 🚀 | High |
| Enhancement | Edit or update a bookmark | 🚀 | High |
| Enhancement | Organize with tags or folders | 🚀 | Medium |
| Enhancement | Import/export bookmarks | 🚀 | Medium |
| Bug/Risk | Handle duplicate slugs on re-add | 🐞 | High |
| Bug/Risk | Validate empty URL submissions | 🐞 | High |
| Bug/Risk | Recover from cleared localStorage | 🐞 | Medium |

## 🚀 Planned features

- 🔍 Search & filter bookmarks — priority: high
- ✏️ Edit or update a bookmark URL — priority: high
- 🏷️ Organize with tags or folders — priority: medium
- 📤 Import/export bookmarks as JSON — priority: medium
- 🎯 Batch operations (select multiple, delete all at once) — priority: low
- 🌐 Sync bookmarks across devices — priority: low
- 📱 Mobile-friendly UI enhancements — priority: low

## 🐞 Known bugs & risks

- 🔴 Duplicate slugs on re-add same URL — priority: high
- ⚠️ Empty URL validation not enforced — priority: high
- 💾 Bookmarks lost when localStorage is cleared — priority: medium
- 🔄 No undo after "Clear all" — priority: medium
- 📏 Long URLs may overflow bookmark display — priority: low
- 🔐 No protection if localStorage is manually modified — priority: low
